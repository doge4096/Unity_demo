# 肉鸽游戏（Unity 面试项目）

基于 Unity 2022.3 的俯视视角肉鸽（Roguelike）游戏 Demo，包含角色选择、近战/远程双角色、分层动画系统等核心功能。

## 技术要点

- **Unity 2022.3.62f1c** + 原生 UGUI / TextMeshPro
- **Humanoid 动画系统**：角色与动画全部使用人形骨骼，动画通过 Avatar 映射驱动
- **双层状态机**（近战）：Base Layer 负责移动/待机（下半身），UpperBody 层负责攻击/格挡（上半身，配合 Avatar Mask），实现「边跑边攻击」「移动中格挡」
- **动画播放速度随移动速度线性变化**（走路 0.6 倍 → 冲刺 1.2 倍，可调）：走路复用持枪跑步动画并降速播放，步频接近真实走路
- **瞄准走路方向混合**：AimWalk 2D 混合树（AimX/AimZ 驱动），前/右/后/左四方向动画 + 中心节点，瞄准时斜向移动动画方向跟随
- **事件总线 + ScriptableObject** 角色数据配置

## 游戏玩法

- 进入游戏后选择角色（近战 / 远程）
- 近战：扇形范围挥砍、三段连击、格挡减伤
- 远程：瞄准（右键）+ 射击、射击后瞄准保持、换弹、持枪待机/移动
- 随机 Buff 奖励（攻击 / 防御 / 生命 / 速度）

## 操作方式

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 冲刺 | Shift（开关切换） |
| 攻击 | 鼠标左键 / Ctrl |
| 格挡（近战） | 鼠标右键（按住） |
| 跳跃 | 空格（二段跳） |
| 攻击范围指示器 | Tab（按住，近战） |

## 项目结构

```
Assets/
├── Art/                # 模型、动画、贴图、材质、动画控制器
│   ├── Animations/     # 动画（Mixamo）与动画控制器
│   ├── Models/         # 角色与武器模型
│   └── Masks/          # Avatar Mask（上半身分层用）
├── Scripts/
│   ├── Camera/         # 第三人称相机
│   ├── Characters/     # 角色基类、玩家控制器、近战/远程角色
│   ├── Combat/         # 武器、投射物、技能、对象池
│   ├── Core/           # 游戏管理器、事件总线
│   └── UI/             # 选人面板、HUD、奖励面板
└── ScriptableObjects/  # 角色与 Buff 数据配置
```

## 运行

1. 使用 Unity 2022.3 打开项目
2. 打开 `Assets/Scenes/SampleScene.unity`
3. 点击 Play，选择角色开始游戏
